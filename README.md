# Multiplication Drill

[![CI/CD Pipeline](https://github.com/multiplicationdrill/multiplicationdrill.github.io/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/multiplicationdrill/multiplicationdrill.github.io/actions/workflows/ci-cd.yml)
[![codecov](https://codecov.io/gh/multiplicationdrill/multiplicationdrill.github.io/branch/master/graph/badge.svg)](https://codecov.io/gh/multiplicationdrill/multiplicationdrill.github.io)

Timed, self-graded multiplication drill. Live at <https://multiplicationdrill.github.io>.

## Features

- Question phase, then answer phase, each with its own timer.
- Four tiers (Easy–Expert) scored by mental-arithmetic cost over `2–99 × 2–99`. See [DIFFICULTY.md](DIFFICULTY.md).
- ✓ / ✗ self-grading by tap, click, `→`/`C` or `←`/`X`.
- Leitner-box spaced repetition persisted in `localStorage`.
- Dark/light theme, persisted.

Supports current evergreen browsers only.

## Stack

TypeScript 7 (`tsc`), Vite 8, custom signals, Vitest, Playwright, ESLint with typescript-eslint, Yarn 1, GitHub Actions, GitHub Pages.

typescript-eslint still needs the TypeScript 6 compiler API, so `typescript` is aliased to `@typescript/typescript6` and TypeScript 7 is installed as `@typescript/native`. `tsc` runs TypeScript 7; `tsc6` runs TypeScript 6.

| `yarn test:all` | Lint, type-check, unit, container E2E |

## Layout

```
src/            app source; unit tests in src/__tests__/
e2e/            Playwright specs; page objects in e2e/pages/
tsconfig.json   solution file referencing tsconfig.app.json and tsconfig.node.json
export.sh       writes docs/llm/dump.txt
```

## Deployment

Pushes to `master` run lint, type-check, unit tests on Node 22/24/26 and E2E on Chromium, Firefox and WebKit, then deploy `dist/` to GitHub Pages.
